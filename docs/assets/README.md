# SPaRE logo

The mark depicts a pathology evaluation form: a small tissue illustration beside three question rows, each with three possible answers and a selected response. Blue matches the application's primary color family; pink and purple distinguish the tissue panel. The SVG assets have transparent backgrounds and scale without rasterization.

- [Light wordmark](spare-logo.svg): for light backgrounds.
- [Dark wordmark](spare-logo-dark.svg): for dark backgrounds.
- [Standalone mark](spare-mark.svg): the symbol without lettering.

The wordmark preserves the capitalization **SPaRE** for **Synthetic Pathology Reader Evaluation**. The detailed mark is used in the README; the application favicon and navigation retain the compact review-check icon for small sizes.

The wordmark uses outlined glyphs from [Inter Display SemiBold](https://github.com/rsms/inter), an [SIL Open Font License](https://github.com/rsms/inter/blob/master/LICENSE.txt) typeface. The SVG files contain paths and do not require a font download or a locally installed font.

## Funding marks

The official [OSCARS logo](https://oscars-project.eu/themes/custom/skeleton/logo.svg) is presented on a white background for legibility. The unmodified EU funding marks come from the European Commission's [English funding-emblem package](https://ec.europa.eu/regional_policy/sources/information-sources/logo-download-center/funded_en.zip): `horizontal/RGB/PNG/EN_FundedbytheEU_RGB_POS.png` and `EN_FundedbytheEU_RGB_NEG.png`, for light and dark backgrounds respectively. The [download centre](https://ec.europa.eu/regional_policy/information-sources/logo-download-center_en) provides usage guidance.

Their inclusion follows the [communication kit for OSCARS funded projects](https://oscars-project.eu/sites/default/files/2024-12/OSCARS-FundedProjects-CommsKit.pdf), which specifies the acknowledgement and both marks. These third-party marks are not covered by this repository's GPLv3 license.
